# PortafolioDigital

Portafolio estático publicado desde `docs/`: `index.html` es la landing, `webs.html` reúne los proyectos web y `videojuegos.html` presenta los videojuegos.

El selector ES/EN guarda la preferencia del visitante para las tres páginas. Los enlaces de redes están en el menú «Redes» de cada barra de navegación. Los fondos animados respetan la preferencia de movimiento reducido del navegador.

En videojuegos, cada globo descubre un proyecto; «Ver todos los proyectos» permite explorar el catálogo directamente. Sin JavaScript se muestran todos los proyectos.

Para agregar o editar traducciones, modifica los textos en español y sus atributos `data-en` o `data-en-html`; las etiquetas accesibles usan `data-en-aria`. Mantén las rutas de imágenes y videos relativas a `docs/`.
